# Logo Negócios Diários

Cores: azul-petróleo `#0E4A57` · amarelo-ipê `#F2B705` · branco `#FFFFFF`
Fonte do nome: **Montserrat** (800 em NEGÓCIOS, 300 em DIÁRIOS, 500 no subtítulo) — já convertida em curvas nos SVGs.

| Arquivo | Onde usar |
|---|---|
| `logo-horizontal-fundo-escuro.svg` | Cabeçalho e rodapé do site (Admin › Identidade do site › **Logo completo**) |
| `logo-horizontal-fundo-claro.svg` | E-mails, documentos, propostas, fundo branco |
| `logo-vertical-fundo-claro.svg` | Cartão de visita, banner, materiais impressos |
| `simbolo-fundo-escuro.svg` | Admin › **Símbolo para fundo escuro** |
| `simbolo-quadrado.svg` | Admin › **Símbolo para fundo claro** (gera o favicon), ícone de app, foto de perfil |
| `favicon.svg` | Versão simplificada para 16–32 px |
| `*.png` | Mesmas peças em imagem, para WhatsApp, redes sociais e quem não abre SVG |

Regras: não distorcer, não mudar as cores, manter espaço livre em volta igual à largura da perna do "N".
